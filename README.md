# DhurkaBookMart

## Online Book Shopping Web Application

DhurkaBookMart is a simple online book shopping web application.

## Features

- User Registration
- User Login
- View Available Books
- Add Books to Cart
- View Shopping Cart

## Technologies Used

- Java
- JSP
- Servlet
- Maven
- Apache Tomcat
- HTML
- GitHub
